# No Vertical Culling (NeoForge 1.21.1)

Убирает вертикальное отсечение секций в Sodium: с большой высоты
(например, 574) земля видна до дна мира вместо среза ±дистанция рендера.

## Как собрать
1. Создай свой репозиторий на GitHub, загрузись туда содержимое папки (drag&drop).
2. Actions -> Build NoVerticalCull -> Run workflow.
3. Забери артефакт noverticalcull из завершившегося запуска.
4. Положи jar в папку mods вместе с Sodium 0.8.13.

## Если сборка прошла, а игра крашится
При краше с InvalidInjectionException на isWithinRenderDistance —
это ожидаемая итерация: в сообщении краша указана фактическая сигнатура
метода. Пришли лог, сигнатуру поправят за один заход.
